# Requisitos não funcionais 

| ID     | Requisito                    | Prioridade | Descrição                                                                                                                                                                          |
| ------ | ---------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RNF-01 | Segurança de acesso          | Alta       | O sistema deve implementar mecanismos de autenticação e autorização, garantindo que cada usuário acesse somente as funcionalidades permitidas ao seu perfil.                       |
| RNF-02 | Proteção de dados            | Alta       | O sistema deve proteger os dados pessoais dos usuários contra acessos, alterações e divulgações não autorizadas, observando os princípios da LGPD.                                 |
| RNF-03 | Integridade dos dados        | Alta       | O sistema deve garantir a consistência das informações durante operações de cadastro, atualização e registro de execução dos treinos.                                              |
| RNF-04 | Persistência das informações | Alta       | O sistema deve garantir a persistência dos dados cadastrados, treinos e registros de execução armazenados no servidor.                                                             |
| RNF-05 | Desempenho                   | Alta       | O sistema deve responder às solicitações dos usuários em tempo adequado, evitando atrasos que prejudiquem a consulta e o acompanhamento dos treinos.                               |
| RNF-06 | Usabilidade                  | Alta       | As interfaces devem apresentar organização intuitiva, com navegação simples e informações claras, facilitando a utilização por professores e alunos.                               |
| RNF-07 | Responsividade               | Alta       | As plataformas devem adaptar suas interfaces a diferentes tamanhos de tela, permitindo utilização em computadores, tablets e smartphones.                                          |
| RNF-08 | Compatibilidade              | Média      | O sistema deve funcionar nos principais navegadores modernos, mantendo compatibilidade com diferentes sistemas operacionais e dispositivos.                                        |
| RNF-09 | Disponibilidade              | Alta       | O sistema deve manter suas funcionalidades acessíveis durante o funcionamento normal da infraestrutura, considerando possíveis interrupções dos serviços de hospedagem.            |
| RNF-10 | Recuperação de dados         | Alta       | O sistema deve possuir mecanismos de backup e restauração dos dados armazenados no servidor, permitindo sua recuperação em situações de falha ou perda de dados.                   |                                              |
| RNF-11 | Manutenibilidade             | Média      | A arquitetura deve permitir a manutenção e evolução dos componentes de forma organizada, reduzindo o impacto de alterações sobre as demais funcionalidades.                        |
| RNF-12 | Escalabilidade               | Média      | A arquitetura deve permitir a expansão dos recursos computacionais e atender ao crescimento da quantidade de usuários e operações sem exigir uma reformulação completa do sistema. |
